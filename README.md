# 🎓 Башкирская языковая школа (Bashkir Language School)

Платформа краудсорсинга и экспертной верификации параллельного корпуса башкирско-русских переводов с геймификацией в стиле Duolingo.

Разработано в рамках хакатона (Задача 3: Краудсорсинг переводов башкирского языка).

---

## 🚀 Архитектура и стек технологий

Проект построен на **едином высокопроизводительном бэкенде на Golang (Unified Dual-Ingress Binary)**:
- **Один процесс Go** одновременно обслуживает:
  1. **REST API** (Chi v5) для Web SPA и Telegram Mini App (TMA).
  2. **Telegram Bot** (`telebot.v3`) с интерактивными кнопками и FSM.
  - Бизнес-логика, начисление XP, валидация и консенсус переиспользуются на 100% без лишних HTTP-запросов между сервисами.
- **База данных**: PostgreSQL 16 (пул соединений `pgx/v5`, автоматическая миграция схемы при старте).
- **Кэш и лидерборды**: Redis 7 (`go-redis/v9`) — ZSET для мгновенного ранжирования лидеров и FSM для сессий бота.
- **Контейнеризация**: Multi-stage Dockerfile на базе `alpine` (образ весит < 25 MB).

## 🧠 Ключевая бизнес-логика

1. **Дневные карточки заданий (5 фрагментов в день)**:
   - Пользователь получает пачку из 5 предложений башкирского текста с черновым переводом.
   - Поддерживаются действия: `confirmed` (подтвердить), `edited` (предложить исправление), `reported_error` (пожаловаться на ошибку).
2. **Античит с контрольными ловушками (Honeypot Traps)**:
   - Случайные карточки подмешивают заведомо искаженный машинный перевод.
   - Если пользователь бездумно нажимает «Подтвердить», он не получает бонус за ловушку.
   - Если пользователь замечает ловушку (исправляет или сообщает об ошибке), ему начисляется **+30 бонусных XP**, а ловушка ни при каких условиях не попадет в базу эталонов.
3. **Движок консенсуса большинства**:
   - $\ge 3$ одинаковых голосов и $\ge 60\%$ согласия $\rightarrow$ автоматический перевод в статус `confirmed` с записью в таблицу `confirmed_translations` (Раздел 5 ТЗ).
   - Спорные переводы (разброс мнений) или жалобы на ошибку $\rightarrow$ статус `expert_review` (эскалация лингвистам УФИЦ РАН).
4. **Фильтр ненормативной лексики и спама**:
   - Проверка предложенных вариантов на нецензурные корни, транслит, повторы символов и спам.
   - При попытке отправить непристойный текст выдается предупреждение, а сабмит отклоняется.
5. **Геймификация и LMS для школ**:
   - +10 XP за подтверждение, +25 XP за исправление, +5 XP за сообщение об ошибке.
   - +30 XP за раскрытие ловушки.
   - +50 XP бонус за закрытие дневной нормы (5 карточек).
   - Стрики (серии дней подряд) и лидерборды школ / учеников.
   - LMS-аналитика для учителей по классам.
6. **Экспорт эталонного датасета (Раздел 5 ТЗ)**:
   - Эндпоинт `GET /api/v1/export/translations` для скачивания очищенного корпуса башкирско-русских пар.

## 📁 Структура репозитория

```
├── backend/
│   ├── cmd/
│   │   ├── server/main.go       # Точка входа единого бэкенда (HTTP + Telegram Bot)
│   │   └── seeder/main.go       # Наполнитель демо-данными (литература, фрагменты, классы)
│   ├── internal/
│   │   ├── config/              # Загрузка переменных окружения
│   │   ├── domain/              # Сущности, DTO, интерфейсы репозиториев, ошибки
│   │   ├── usecase/             # Чистая бизнес-логика (Auth, Task, Consensus, Gamification, LMS, Export)
│   │   ├── delivery/
│   │   │   ├── http/            # REST API хэндлеры и middleware (Chi v5, JWT, CORS)
│   │   │   └── bot/             # Telegram-бот хэндлеры, меню, клавиатуры (telebot.v3)
│   │   ├── repository/
│   │   │   ├── postgres/        # Реализация репозиториев на pgx/v5
│   │   │   ├── redis/           # ZSET лидерборды и FSM бота
│   │   │   └── migrator.go      # Авто-мигратор схемы БД
│   │   └── pkg/                 # Утилиты (модерация, хеширование, JWT, валидатор initData TMA)
│   ├── migrations/              # SQL-миграции схемы PostgreSQL
│   └── Dockerfile               # Легковесный multi-stage build
├── docker-compose.yml           # PostgreSQL 16 + Redis 7 + Go Backend
├── .env.example                 # Шаблон переменных окружения
└── README.md
```

## 🛠️ Запуск проекта

### 1. Переменные окружения
Скопируйте шаблон:
```bash
cp .env.example .env
```
Укажите актуальный токен Telegram бота (`TELEGRAM_BOT_TOKEN`) в `.env`.

### 2. Запуск через Docker Compose
```bash
docker compose up -d --build
```
Сервисы:
- REST API: `http://localhost:8080`
- Документация/экспорт: `http://localhost:8080/api/v1/export/translations`
- PostgreSQL: `localhost:5432`
- Redis: `localhost:6379`
- Telegram Bot: запускается автоматически в режиме Long Polling внутри контейнера бэкенда.

### 3. Запуск юнит-тестов
```bash
docker run --rm -v "${PWD}/backend:/app" -w /app golang:1.22-alpine go test -v ./...
```
Все 30+ тестов покрывают модерацию, консенсус, ловушки honeypot, стрик, начисление XP и HTTP эндпоинты.
