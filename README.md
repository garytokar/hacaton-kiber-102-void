# 🎓 «ЙӘНЛӘНДЕР» — Цифровой корпус и школа башкирского языка

> **«Сохраняй язык. Создавай наследие»**  
> Интерактивная платформа краудсорсинга, обучения и экспертной верификации параллельного корпуса башкирско-русских переводов с геймификацией по ТЗ хакатона.

---

## 🚀 Быстрый запуск одной командой (Docker Compose)

Всё приложение (PostgreSQL, FastAPI Backend и React Frontend) поднимается одной командой:

```bash
docker compose up --build
```

После запуска сервисы доступны по адресам:
* 🌐 **Веб-платформа (React SPA)**: [http://localhost:3000](http://localhost:3000)
* 📚 **Интерактивная документация API (Swagger / OpenAPI)**: [http://localhost:8000/docs](http://localhost:8000/docs)
* 🗄 **PostgreSQL**: `localhost:5432` (`bashkir_school`, пользователь: `postgres`, пароль: `secret`)

---

## 💻 Локальный запуск для разработки (Zero-Config с SQLite)

Для мгновенного тестирования без Docker бэкенд по умолчанию использует встроенную базу данных SQLite (`yanlander.db`), уже предзаполненную реальными текстами башкирской литературы, пословицами и демо-пользователями.

### 1. Бэкенд (Python FastAPI)
```bash
cd backend
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
# source venv/bin/activate

pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```
API будет доступно на `http://127.0.0.1:8000`, документация Swagger — на `http://127.0.0.1:8000/docs`.

### 2. Фронтенд (React 19 + TypeScript + Vite)
```bash
cd frontend
npm install
npm run dev
```
Фронтенд запустится на [http://127.0.0.1:3000](http://127.0.0.1:3000) и автоматически проксирует запросы `/api` на бэкенд (порт 8000).

## 🧠 Бизнес-логика консенсуса и геймификации по ТЗ

1. **Консенсус 3 голосов**:
   * Перевод находится в статусе `pending` до тех пор, пока не наберёт **3 подтверждения** от независимых пользователей.
   * При достижении 3 голосов перевод автоматически переходит в статус `confirmed` и пополняет общедоступную **Сокровищницу языка**.
   * При наличии замечаний перевод эскалируется в статус `expert_review` экспертам УФИЦ РАН.
2. **Таблица начисления опыта (XP) и монет**:
   * Подтверждение перевода: **+5 XP** (+2 монеты Ҡурай);
   * Подтверждение сложного фрагмента: **+8 XP** (+2 монеты Ҡурай);
   * Предложение своего перевода: **+8 XP** (+5 монет Ҡурай);
   * Выполнение ежедневного квеста: **+15...+25 XP** (+5...10 монет Ҡурай).
3. **10 уровней мастерства**:
   * От *1. Начинающий (0 XP)* до *10. Легенда языка (15 000+ XP)* с динамическим пересчётом и прогресс-баром.
4. **Серия активности (Streak)**:
   * Увеличивается при подтверждении перевода или предложении своего варианта (не накручивается за простой вход).
   * Защита от сгорания с помощью артефакта «Оберег Салавата» (Streak Freeze).
