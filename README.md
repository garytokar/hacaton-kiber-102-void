# 🎓 «ЙӘНЛӘНДЕР» — Башкирская языковая школа (Bashkir Language School)

Интерактивная платформа краудсорсинга, обучения и экспертной верификации параллельного корпуса башкирско-русских переводов с геймификацией и современным веб-интерфейсом.

Разработано в рамках хакатона (Задача: Краудсорсинг переводов башкирского языка и сохранение цифрового языкового наследия).

---

## 🎨 Дизайн и UI/UX (Figma «Сайт в синей палитре»)

Интерфейс платформы реализован в строгом соответствии с утверждённым дизайн-макетом Figma в глубокой сапфировой палитре с традиционными башкирскими мотивами:
* **Цветовая палитра**:
  * Основной тёмно-синий: `#0C2340` (полноэкранный сайдбар, кнопки подтверждения)
  * Королевский синий акцент: `#1E50A0` / `#2563EB` (активные табы, разделители, прогресс-бары)
  * Фоновый цвет: `#F4F6F9` (чистый нейтральный фон контента)
  * Акцентные бейджи: `#EEF2FF` / золотой `#F59E0B` (монеты Ҡурай, медали лидеров)
* **Аутентичные визуальные ассеты**:
  * Иллюстрация Уральских гор Башкортостана с геометрическим солярным орнаментом
  * Карточка ежедневного задания с традиционным башкирским инструментом (домбра/кубыз) и кнопкой синтеза речи
  * Сокровищница языка с карточкой «ҡояш» (солнце) и картиной рассвета над хребтами
  * Векторный башкирский национальный орнамент солнца в логотипе
* **Экраны и разделы веб-приложения**:
  * **Главная / Dashboard**: Hero-баннер, слайдер ежедневных заданий с аудио, 3 ключевые карточки (Сокровищница, Рейтинг, Достижения)
  * **Ежедневное задание (`/task`)**: интерактивная проверка переводов, голосование, предложение правок, история ревизий и озвучка
  * **Сокровищница языка (`/treasury`)**: общедоступная база проверенных переводов, поиск, фильтры по категориям и экспорт корпуса в CSV
  * **Рейтинг сообщества (`/leaderboard`)**: пьедестал лидеров с табами «Пользователи», «Школы», «Команды», фильтрация по XP и точности
  * **Достижения (`/achievements`)**: система наград с бейджами и прогрессом майлстоунов («Семидневный хранитель»)
  * **Словарь (`/dictionary`)**: персональный лексикон с режимом флеш-карточек (Flashcard trainer) для интервального повторения
  * **Экспедиции (`/expeditions`)**: еженедельные командные миссии для объединения школ республики
  * **Профиль (`/profile`)**: статистика Хранителя, магазин оберегов (Streak Freeze) и GitHub-style тепловая карта активности за 60 дней
  * **Панель модератора (`/admin`)**: экспертная валидация спорных переводов, эскалация лингвистам, управление ролями и добавление фрагментов в корпус

## 🚀 Архитектура и стек технологий

### Frontend
* **Фреймворк**: React 19 + TypeScript + Vite 8
* **Стилизация**: Tailwind CSS (утилитарные стили, кастомная сапфировая палитра)
* **Иконки и анимации**: Lucide React, Canvas Confetti
* **Аудио**: Web Speech API для произношения башкирских слов
* **Сборка**: Multi-stage Dockerfile на базе `nginx:alpine`

### Backend
* **Единый бинарник на Golang (Unified Dual-Ingress Binary)**:
  1. **REST API** (Chi v5) для Web SPA и Telegram Mini App (TMA).
  2. **Telegram Bot** (`telebot.v3`) с интерактивными кнопками и FSM.
  - Бизнес-логика, начисление XP, валидация и консенсус переиспользуются на 100% без лишних HTTP-запросов между сервисами.
* **База данных**: PostgreSQL 16 (пул соединений `pgx/v5`, автоматическая миграция схемы при старте).
* **Кэш и лидерборды**: Redis 7 (`go-redis/v9`) — ZSET для мгновенного ранжирования лидеров и FSM для сессий бота.
* **Контейнеризация**: Multi-stage Dockerfile на базе `alpine` (образ весит < 25 MB).

## 🧠 Ключевая бизнес-логика и алгоритмы

1. **Дневные карточки заданий (5 фрагментов в день)**:
   * Пользователь получает пачку из предложений башкирского текста с черновым переводом.
   * Поддерживаются действия: `confirmed` (подтвердить), `edited` (предложить исправление), `reported_error` (пожаловаться на ошибку).
2. **Античит с контрольными ловушками (Honeypot Traps)**:
   * Случайные карточки подмешивают заведомо искаженный машинный перевод.
   * Если пользователь бездумно нажимает «Подтвердить», он не получает бонус за ловушку.
   * Если пользователь замечает ловушку (исправляет или сообщает об ошибке), ему начисляется **+30 бонусных XP**, а ловушка ни при каких условиях не попадет в базу эталонов.
3. **Движок консенсуса большинства**:
   * $\ge 3$ одинаковых голосов и $\ge 60\%$ согласия $\rightarrow$ автоматический перевод в статус `confirmed` с записью в таблицу `confirmed_translations`.
   * Спорные переводы (разброс мнений) или жалобы на ошибку $\rightarrow$ статус `expert_review` (эскалация лингвистам УФИЦ РАН).
4. **Фильтр ненормативной лексики и спама**:
   * Проверка предложенных вариантов на нецензурные корни, транслит, повторы символов и спам.
   * При попытке отправить непристойный текст выдается предупреждение, а сабмит отклоняется.
5. **Геймификация и LMS для школ**:
   * +10 XP за подтверждение, +25 XP за исправление, +5 XP за сообщение об ошибке.
   * +30 XP за раскрытие ловушки.
   * +50 XP бонус за закрытие дневной нормы (5 карточек).
   * Стрики (серии дней подряд) с защитой от сгорания (Streak Freeze за монеты Ҡурай) и лидерборды школ / учеников.
   * LMS-аналитика для учителей по классам.
6. **Экспорт эталонного датасета**:
   * Эндпоинт `GET /api/v1/export/translations` для скачивания очищенного корпуса башкирско-русских пар (CSV / JSON).

## 🛠️ Запуск проекта

### 1. Переменные окружения
Скопируйте шаблон:
```bash
cp .env.example .env
```
Укажите актуальный токен Telegram бота (`TELEGRAM_BOT_TOKEN`) в файле `.env`.

### 2. Запуск бэкенда и БД через Docker Compose
```bash
docker compose up -d --build
```
Сервисы:
* **REST API**: `http://localhost:8080`
* **Документация и экспорт корпуса**: `http://localhost:8080/api/v1/export/translations`
* **PostgreSQL**: `localhost:5432`
* **Redis**: `localhost:6379`
* **Telegram Bot**: запускается автоматически в режиме Long Polling внутри контейнера бэкенда.

### 3. Запуск фронтенда (React SPA)
```bash
cd frontend
npm install
npm run dev
```
Фронтенд запустится на `http://localhost:3000` (с проксированием API-запросов на бэкенд).

### 4. Запуск тестов бэкенда
```bash
docker run --rm -v "${PWD}/backend:/app" -w /app golang:1.22-alpine go test -v ./...
```
Все 30+ тестов покрывают модерацию, консенсус, ловушки honeypot, стрики, начисление XP и HTTP эндпоинты.
